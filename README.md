# Raycast Strike

HTML/JS 레이캐스팅 FPS (팀 데스매치). 빌드 없이 정적 파일만으로 동작합니다.

- PC: `index.html`을 브라우저로 열기 (WASD + 마우스)
- 모바일: 웹 주소로 접속하면 자동으로 터치 UI (왼쪽 조이스틱, 오른쪽 드래그 시점, 발사/점프/장전/스코프/무기 버튼)

## 폰에서 접속하려면 (배포)

폰은 PC의 파일을 직접 열 수 없으므로 웹 주소가 필요합니다. 폴더 전체(`index.html`, `js/`)를 정적 호스팅에 올리면 됩니다.

### Netlify (가장 간단)
1. https://app.netlify.com/drop 접속
2. 이 폴더(`raycast-fps`)를 드래그 앤 드롭
3. 발급된 `https://...netlify.app` 주소를 폰에서 열기

### GitHub Pages
1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 올리기
2. 저장소 Settings → Pages → Branch: `main` / root 선택
3. `https://<계정>.github.io/<저장소>/` 주소를 폰에서 열기

> 업로드한 게임은 주소를 아는 누구나 접속할 수 있습니다(공개).

## 같은 Wi-Fi에서 빠르게 테스트 (개발용)
PC에서 이 폴더로 이동해 `python -m http.server 8000` 실행 후, 폰 브라우저에서 `http://<PC의 IP>:8000` 접속.

## 모바일 참고
- 가로 모드 전용입니다. 세로면 회전 안내가 나오고, 시작 시 전체화면 + 가로 고정을 시도합니다(Android Chrome).
- iPhone Safari는 전체화면/방향 고정을 지원하지 않습니다. 공유 → "홈 화면에 추가"로 실행하면 주소창 없이 즐길 수 있습니다.
- 앱 전환, 세로 전환, 전체화면 해제 시 자동 일시정지됩니다.

## 개발용 URL 옵션
`?mobile=1` 데스크톱에서 모바일 UI 강제 · `?auto=1` AI가 플레이어 조종 · `&sim=N` N프레임 미리 시뮬레이션 · `&manual=1` 사람 조작 경로 · `&place=1` 적 배치 · `&test=1` 터치 입력 자동 테스트 · `&debug=1` 디버그 출력
